How to free up Android storage safely

Before deleting anything, find out what is using space. This careful checklist helps you review downloads, photos, videos, and app data without guessing.

A phone can run short on storage because of photos, videos, downloads, offline media, large apps, and temporary files. The safest approach is to review each category and remove only items you recognize and no longer need.

Back up first. Before deleting photos, videos, documents, or chats, make sure you have another copy if you may want them later. Deleting from a synced service can sometimes remove an item from more than one device.

1. See what is using space

Open Settings → Storage, or search Settings for Storage. Review the categories shown on your phone. The exact names and layout depend on the manufacturer and Android version.

2. Review Downloads and large files

Open your Files app and look through Downloads, large files, and documents. Sort by size if the app offers that option. Delete only files you recognize and no longer need. If a file might matter later, move a copy to a trusted backup location first.

3. Check photos and videos

Videos can take up substantial space. Review old screen recordings, duplicate exports, and clips you no longer need. Confirm that anything important is backed up before removing the local copy. Check the backup service's own instructions so you understand whether deleting a file also deletes its cloud copy.

4. Uninstall apps you no longer use

Review your installed apps and remove ones you no longer need. If an app stores documents or game progress locally, check whether that data is synced or backed up before uninstalling it.

5. Be careful with cached data

Some Android versions let you clear an individual app's cache from its App info or Storage screen. Cache is temporary data, but clearing it may make an app load content again or sign you out in some cases. Do not confuse Clear cache with Clear storage or Clear data; the latter can remove local app information and reset the app.

What not to delete

  • Do not remove unfamiliar system folders or files just because their names look unusual.
  • Do not install an unknown “cleaner” app that asks for broad access to your files or other sensitive data.
  • Do not empty a Trash or Recently deleted folder until you are sure you will not need those files.

Make a simple monthly check

Once a month, check the Storage screen, review large downloads, and remove media you have already backed up. Small, deliberate cleanups are safer than deleting large groups of files in a hurry.

The takeaway

Check storage first, back up anything important, then review downloads, media, unused apps, and cache one category at a time. Avoid unknown system files and be especially careful with Clear storage or Clear data.
